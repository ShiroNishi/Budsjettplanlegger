Budsjettplanlegger

Lag en enkel budsjettplanlegger som hjelper brukeren med å få oversikt over inntekter og utgifter.
Brukeren skal kunne:
Legge inn inntekter med beløp og beskrivelse
Legge inn utgifter med beløp og kategori
Se total sum for inntekter, utgifter og saldo
Applikasjonen skal oppdatere tallene automatisk når nye poster legges til. Det skal være mulig å se en oversikt over alle registrerte poster.
Strukturen i programmet skal gjøre det enkelt å legge til nye beregninger eller visninger senere. Med andre ord: bruk MVC, parameter og gjenbruk av elementer. 
Bonus
Sorter utgifter etter beløp eller kategori
Marker utgifter som overstiger en viss grense
Vis største og minste utgift
